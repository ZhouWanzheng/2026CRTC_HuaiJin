# CRTC2026 中期考核 · 视觉模块技术文档

| 项目   | 内容                                      |
| ---- | --------------------------------------- |
| 模块   | 视觉方向（1 人）                               |
| 硬件   | OpenMV Cam H7（固件 4.5.9） + STM32F103C8T6 |
| 工作模式 | 半自动（车体遥控到位，视觉负责识别与引导）                   |

## 一、设计总纲

### 1.1 竞赛情景分析

- 规则要求**先捡黄色方块**，黄为主目标，白为次目标；
- 场馆光照不可控，与调试环境色温不同；
- 目标是 30×30×30 mm 的**镂空框架**，边框细、易被拆散；
- 场地有黄黑相间标识线等同色干扰；
- 目标常在操作手视线外，肉眼判不了方向和距离；
- 车体由人遥控，视觉需在行进中持续报方位。

### 1.2 功能需求

- **颜色分割**：未知光照下分出目标色与背景；
- **镂空判别**：分开镂空框架与实心色块，本任务最关键；
- **抗干扰**：排除反光、场地条纹等非目标色块；
- **坐标输出**：固定帧格式发 STM32，且能区分「丢失」与「在角落」；
- **可调试**：识别不到时能定位被哪条判据筛掉，不盲改阈值。

### 1.3 方案选型

| 方案                  | 成本      | 抗光照 | 结论                           |
| ------------------- | ------- | --- | ---------------------------- |
| RGB 通道阈值            | 0       | 极差  | ❌ 三通道同时受光照影响，光照减半即失效         |
| HSV（电脑端）            | 0       | 中   | ⚠️ 仅过渡验证，色相在低饱和度下跳变          |
| **OpenMV + LAB 阈值** | 0（复用板载） | 较好  | ✅ **采用**                     |
| YOLO 目标检测           | 高       | 好   | ❌ 成本撞线 + 主控算力不足 + 样本极少，属过度设计 |
| 手机 + IP Webcam      | 0       | 中   | ❌ 鸿蒙系统无法安装第三方摄像头 APK，通路不可行   |

> 选 LAB 的理由：L 单独承载亮度、A/B 稳定，放宽 L 范围即可适应不同场景；HSV 色相在低饱和度下会跳变，RGB 三通道互相耦合。

### 1.4 模块划分

| 模块        | 职责                                |
| --------- | --------------------------------- |
| 视觉识别模块    | 图像采集 → LAB 分割 → 四道判据筛选 → 输出中心像素坐标 |
| 串口通信模块    | 打包 12 字节帧发给 STM32，115200 8N1 单向   |
| 机械臂视觉引导模块 | 图像坐标 → 机械臂逆解算（目前还在进行中）            |
| 硬件与安装模块   | 相机选型、安装位置、成本与重量约束                 |

## 二、模块设计

### 2.1 视觉识别模块

分辨率 **QQVGA 160×120**。

按规则先找黄色，找不到再看白色；白色那路备着后面对付白色方块。两路判据相同，只是阈值不同。

分割后串行过四道判据：

| 判据             | 排除对象               | 当前参数                                                    |
| -------------- | ------------------ | ------------------------------------------------------- |
| LAB 颜色阈值       | 非目标色               | 黄 `(25,80,64,-24,47,108)` / 白 `(96,100,-16,14,-35,127)` |
| 像素数上下限         | 下限排噪点；上限排白墙反光、整片过曝 | 下限 30 / 上限 99999（待收紧）                                   |
| **密度 density** | **实心色块**           | **0.20 ~ 0.65**                                         |
| 宽高比            | 细长反光条、场地条纹         | 0.60 ~ 1.70                                             |

**密度判据是本模块的关键设计。** `density = 像素数 / (框宽 × 框高)`。实心块约 0.85~~1.00，镂空框架约 0.25~~0.60，两者分得开。不用拼边框、判形状，一次除法就知道色块是不是空心。

它还依赖另外两个设置，缺一即失效：

| 依赖项                   | 值 | 缺失后果                                        |
| --------------------- | - | ------------------------------------------- |
| `merge=True`          | 开 | 每条边各成实心细条，密度全≈1.0，镂空特征消失                    |
| `x_stride / y_stride` | 2 | 步长是隔几像素采样一次，**不是尺寸筛选**；改到 30 会漏掉细边，边框断裂无法合并 |
| `margin`              | 8 | 合并时允许的最大间隙（像素）                              |

### 2.2 串口通信模块

**帧格式：12 字节，115200 8N1，单向（视觉 → 电控）**

| 字节     | 名称   | 值 / 说明                                       |
| ------ | ---- | -------------------------------------------- |
| 0      | 帧头 1 | `0x2C`                                       |
| 1      | 帧头 2 | `0x12`                                       |
| 2      | 颜色   | `'Y'`=0x59 黄 / `'W'`=0x57 白 / `'A'`=0x41 未识别 |
| 3 ~ 6  | X 坐标 | float，小端，4 字节                                |
| 7 ~ 10 | Y 坐标 | float，小端，4 字节                                |
| 11     | 帧尾   | `0x5B`                                       |

`ustruct.pack("<bbbffb", 0x2C, 0x12, color, x, y, 0x5B)`

### 2.3 机械臂视觉引导模块

坐标变换 `arm_x = cx - ARM_ORIGIN_X`、`arm_y = ARM_ORIGIN_Y - cy`（图像 Y 向下、机械臂 Y 向前，故取反）。`ARM_ORIGIN_X/Y` 是基座原点在画面中的位置，需上机标定，当前暂用画面中心 (80, 60)。

**逆解算走几何法（余弦定理），不用矩阵或 DH 参数。**

### 2.4 硬件与安装模块

| 项目         | 内容                                                    |
| ---------- | ----------------------------------------------------- |
| 相机         | OpenMV Cam H7，固件 4.5.9（须用旧 `sensor` API，导入 `csi` 会报错） |
| 分辨率 / 帧率   | QQVGA 160×120，实测 20~30 fps                            |
| 安装位置       | 车头上方前倾，视野覆盖抓取区（俯角待定）                                  |
| 与 STM32 连线 | OpenMV P4(TX) → STM32 USART3 RX，115200 8N1，两边共地       |
| 供电         | 5 V 独立供电并与 STM32 共地，不从开发板取电                           |

## 三、关键决策速览

| # | 决策       | 选择                    | 理由                                        |
| - | -------- | --------------------- | ----------------------------------------- |
| 1 | 色彩空间     | LAB 六元组               | L 单独承载亮度，放宽 L 即可换场景；HSV 色相在低饱和度下跳变        |
| 2 | 自动白平衡/增益 | **全部关闭**              | 白平衡把画面拉向中性灰，增益改变 L 值；不关则换环境后调参全废          |
| 3 | 坐标滤波     | 中值滤波（窗口 5）            | 尖峰直接排除；滑动平均会把尖峰摊成持续偏差，PID 会当成真偏移一直修正      |
| 4 | 镂空判据     | `density()` 0.20~0.65 | 一次除法判出框内是空的，比拼边框再判形状更短更稳                  |
| 5 | 串口帧      | 12 字节 float           | 电控 `openmv.c` 写死 12 字节、按 float 解析，以既有实现为准 |
| 6 | 目标丢失     | 发 `'A'`，不发 `(0,0)`    | `(0,0)` 是合法坐标，无法与「目标在角落」区分                |
| 7 | 分辨率      | QQVGA 160×120         | 步长降到 2 后仍要保帧率；改 float 后无 0~255 截断风险       |
| 8 | 机械臂控制    | 逆解算（几何法）              | 开源逆解是它自己臂的尺寸，按本队尺寸重推即可；脉宽仍须逐关节标定          |
